# [326. Power of Three](https://leetcode.com/problems/power-of-three/)
**Difficulty:** `Easy` | **Tags:** `math`, `recursion`

---

## Problem Description
Given an integer `n`, return *`true` if it is a power of three. Otherwise, return `false`*.

An integer `n` is a power of three, if there exists an integer `x` such that `n == 3x`.

**Example 1:**

```
Input: n = 27
Output: true
Explanation: 27 = 33
```

**Example 2:**

```
Input: n = 0
Output: false
Explanation: There is no x where 3x = 0.
```

**Example 3:**

```
Input: n = -1
Output: false
Explanation: There is no x where 3x = (-1).
```

**Constraints:**

* `-231 <= n <= 231 - 1`

**Follow up:** Could you solve it without loops/recursion?

---

## Solution & Editorial
# Intuition
The problem asks us to determine if a given integer $n$ is a power of three. Since powers of three are generated by repeatedly multiplying by $3$ starting from $1$, we can reverse this process by repeatedly dividing $n$ by $3$ until it either reaches $1$ or fails the divisibility condition.

# Approach
1. Check base cases: if $n == 0$, return `false` as zero is not a power of three. If $n == 1$, return `true` because $3^0 = 1$.
2. Check if $n$ is divisible by $3$ using the modulo operator ($n \% 3 == 0$).
3. If divisible, recursively call `isPowerOfThree(n / 3)`. Otherwise, return `false`.

### Visual Trace (Example 1: n = 27)
- `isPowerOfThree(27)`: $27 \% 3 == 0 \implies$ calls `isPowerOfThree(9)`
- `isPowerOfThree(9)`: $9 \% 3 == 0 \implies$ calls `isPowerOfThree(3)`
- `isPowerOfThree(3)`: $3 \% 3 == 0 \implies$ calls `isPowerOfThree(1)`
- `isPowerOfThree(1)`: hits base case `n == 1` $\implies$ returns `true`

# Complexity
- Time complexity: $$O(\log_3 n)$$ — In each recursive step, $n$ is divided by $3$, leading to a logarithmic number of divisions.
- Space complexity: $$O(\log_3 n)$$ — The recursion stack depth is proportional to the number of divisions, which is $\log_3 n$.

# Code
```cpp
class Solution {
public:
    bool isPowerOfThree(int n) {
        if(n==0) return false;
        if(n==1) return true;
        if(n%3==0) return isPowerOfThree(n/3);

        return false;
    }
};
```
