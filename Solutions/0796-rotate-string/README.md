# [796. Rotate String](https://leetcode.com/problems/rotate-string/)
**Difficulty:** `Easy` | **Tags:** `string`, `string-matching`

---

## Problem Description
Given two strings `s` and `goal`, return `true` *if and only if* `s` *can become* `goal` *after some number of **shifts** on* `s`.

A **shift** on `s` consists of moving the leftmost character of `s` to the rightmost position.

* For example, if `s = "abcde"`, then it will be `"bcdea"` after one shift.

**Example 1:**

**Input:** s = "abcde", goal = "cdeab"

**Output:** true

**Explanation:**

Rotating `s` to the left by 2 positions moves `"ab"` to the end, resulting in `"cdeab"`, which is equal to `goal`.

**Example 2:**

**Input:** s = "abcde", goal = "abced"

**Output:** false

**Explanation:**

No sequence of rotations of `s` can produce `"abced"`. The characters appear in a different relative order, so `goal` is not a rotation of `s`.

**Constraints:**

* `1 <= s.length, goal.length <= 100`
* `s` and `goal` consist of lowercase English letters.

---

## Solution & Editorial
# Intuition
Any rotated version of a string `s` can be generated by repeatedly popping the front character and appending it to the back. Since the maximum length of `s` is $100$, we can directly simulate this shift process for all possible rotation offsets.

# Approach
1. Get the length of string `s` and store it in `n`.
2. Initialize a counter `k = 0` to track the number of shifts performed.
3. Run a `while` loop up to `n` times. In each iteration:
   - Extract the first character `c = s[0]`.
   - Erase the character at index `0` from `s` using `s.erase(0, 1)`.
   - Append `c` to the back of `s` using `s += c`.
   - Check if the newly rotated string `s` equals `goal`. If so, return `true` immediately.
   - Increment `k`.
4. If the loop completes without finding a match, return `false`.

### Visual Walkthrough for Example 1
`s = "abcde"`, `goal = "cdeab"`, `n = 5`

| Iteration `k` | Operation | Resulting `s` | `s == goal` ||
| :--- | :--- | :--- | :--- | :--- |
| 0 | Initial | `"abcde"` | `false` |
| 1 | Shift left by 1 | `"bcdea"` | `false` |
| 2 | Shift left by 2 | `"cdeab"` | `true` (Return `true`) |

# Complexity
- Time complexity: $$O(N^2)$$, where $$N$$ is the length of string `s`. There are up to $$N$$ shifts, and each shift operation involves string erasure and concatenation which takes $$O(N)$$ time.
- Space complexity: $$O(1)$$ auxiliary space, as modifications are done in-place on the existing string objects without extra containers.

# Code
```cpp
class Solution {
public:
    bool rotateString(string s, string goal) {
        int k = 0;
        int n = s.size();
        while(k < n){
            char c = s[0];
            s.erase(0,1);
            s += c;
            if (s == goal) return true;
            k++;
        }
        return false;
    }
};
```
