## Problem Description
Table: `Sales`

```
+-------------+-------+
| Column Name | Type  |
+-------------+-------+
| sale_id     | int   |
| product_id  | int   |
| year        | int   |
| quantity    | int   |
| price       | int   |
+-------------+-------+
(sale_id, year) is the primary key (combination of columns with unique values) of this table.
Each row records a sale of a product in a given year.
A product may have multiple sales entries in the same year.
Note that the per-unit price.
```

Write a solution to find all sales that occurred in the **first year** each product was sold.

* For each `product_id`, identify the earliest `year` it appears in the `Sales` table.
* Return **all** sales entries for that product in that year.

Return a table with the following columns: **product\_id**, **first\_year**, **quantity,** and **price**.  
Return the result in any order.

| 100        | 2008       | 10       | 5000  |

+------------+------------+----------+-------+

## Solution & Editorial
# Intuition
The problem requires us to find all sales records corresponding to the earliest (first) year each product was sold. Since a product may have multiple sales across different years and even multiple sales in the same year, we first need to determine the minimum year for each product and then retrieve all associated sale rows matching that product and year.

# Approach
1. Use a subquery to group the `Sales` table by `product_id` and find the minimum `year` for each product via `MIN(year)`.
2. Filter the main `Sales` table using a composite tuple condition `(product_id, year)` to match against the subquery results.
3. Select the required columns: `product_id`, `year` aliased as `first_year`, `quantity`, and `price`.

# Complexity
- Time complexity: $$O(N \log N)$$ or $$O(N)$$ depending on the database engine's indexing and join optimization for evaluating the subquery and grouping by `product_id` over $$N$$ rows.
- Space complexity: $$O(N)$$ for storing the temporary intermediate relation generated by the grouping subquery.

# Code
```cpp
# Write your MySQL query statement below
SELECT
    product_id,
    year AS first_year,
    quantity,
    price
FROM Sales
WHERE
    (product_id, year) IN (
        SELECT
            product_id,
            MIN(year) AS year
        FROM Sales
        GROUP BY product_id
    );
```
